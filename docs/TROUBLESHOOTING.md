# Troubleshooting Guide

This guide describes common build, runtime, and network challenges encountered during the development and execution of Napster, accompanied by reproducible resolutions.

---

## 1. Build and Compilation Issues

### Gradle Daemon Heap Exhaustion (`OutOfMemoryError`)
- **Symptoms:** The build halts during `compileArm64FossDebugKotlin` with `java.lang.OutOfMemoryError: Java heap space`.
- **Remedy:**
  - Execute Gradle commands with the `--no-daemon` parameter.
  - Confirm `gradle.properties` allocates adequate memory:
    ```properties
    org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=1024m
    ```

### KSP / Room Schema Stale Compilation
- **Symptoms:** Room symbol errors or missing DAO implementations following Git branch switches.
- **Remedy:** Clean existing generated sources and assemble cleanly:
  ```powershell
  .\gradlew.bat --no-daemon :app:clean :app:assembleArm64FossDebug
  ```

## 2. Audio Streaming and Network Challenges

### HTTP 403 Forbidden / Stream Expiration
- **Symptoms:** Playback stalls with an ExoPlayer `HttpDataSource$InvalidResponseCodeException` reporting HTTP 403.
- **Root Cause:** YouTube streaming URLs generated by InnerTube carry timed authentication signatures (`expire` timestamps) that eventually lapse.
- **Remedy:**
  - Napster automatically purges stale URLs after 4 hours or upon an unrecoverable HTTP 403 event, issuing a fresh InnerTube resolution.
  - Check that network connectivity is stable and that IP address throttling by YouTube is not active. If necessary, configure a proxy within `Settings > Content > Proxy`.

### Spotify Playlist Import Returns No Tracks
- **Symptoms:** The import dialogue displays "0 tracks imported" or fails immediately.
- **Root Cause:** The provided Spotify playlist is either private, collaborative-restricted, or dynamic (such as "Liked Songs" or algorithmic "Made For You" mixes).
- **Remedy:**
  - Verify that the target playlist is configured as **Public** within Spotify.
  - Ensure the URL matches the canonical syntax: `https://open.spotify.com/playlist/{id}`.

## 3. Runtime and Device Specifics

### Playback Notifications Absent on Android 13+ (API 33+)
- **Symptoms:** The ongoing media player controls do not appear in the system notification shade or lock screen.
- **Remedy:** Ensure the `POST_NOTIFICATIONS` runtime permission has been granted under system `Settings > Apps > Napster > Notifications`.

### Liquid Glass Rendering Stutter on Older Hardware
- **Symptoms:** Frame rate dips or UI stutter during list scrolling on devices without hardware-accelerated RenderEffect support.
- **Remedy:** Disable real-time backdrop blur under `Settings > Appearance > Liquid Glass` to utilise flat, solid Material 3 surface containers.
